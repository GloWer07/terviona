# Terviona — Mouse & Audio Database

Независимая база **мышей и аудио** — тир-листы, измерения АЧХ, цены и сравнения.
Названа в честь основателя проекта **GloWer-а**. Бренд — Terviona.

Дизайн: язык **Nothing** — чистый чёрно-белый монохром, dot-matrix текстуры,
тонкие хайрлайны, технический моноширинный стиль. Никаких цветовых акцентов.

---

## Запуск (одна кнопка)

Двойной клик по файлу **`Start Terviona.command`** — сервер стартует и сайт
сам откроется в браузере на `http://localhost:8765/`.

Вручную, если нужно:

```bash
python3 local_server.py            # http://localhost:8765/
python3 local_server.py --host 0.0.0.0   # + просмотр с телефона в той же Wi-Fi
```

Интернет не требуется: авторизация и отзывы (Supabase) отключены, счётчик
аналитики не грузится на localhost. Всё работает офлайн.

## Структура

```
Terviona-Site/
├── Start Terviona.command   ← ЗАПУСК ОДНИМ КЛИКОМ
├── local_server.py          ← локальный сервер с красивыми маршрутами
└── site/                    ← корень сайта
    ├── index.html           ← главная
    ├── category.html        ← страница категории (/mice, /audio)
    ├── faq.html · contact.html · articles.html · article.html
    ├── methodology.html · profile.html
    ├── css/style.css        ← дизайн-система v4 "DOT MATRIX" (Nothing)
    ├── js/                  ← app.js (ядро), category.js, i18n.js, …
    ├── data/                ← КОНТЕНТ: mice.json (152), audio.json (105),
    │                          faq.json, methodology.json, fr_targets.json,
    │                          pricing.json, articles.json, meta.json
    └── img/                 ← изображения устройств, формы мышей, бренд
```

Маршруты повторяют продакшен-Nginx: `/mice`, `/mice/<устройство>`, `/audio`,
`/articles`, `/methodology`, `/user/…`.

## Данные

Контент правится правкой JSON в `site/data/`:
- `mice.json` — мыши: тир, цена, сенсор, свитчи, вес, формы, хваты;
- `audio.json` — аудио: категории (IEM, TWS, полноразмерные, гарнитуры, ЦАП),
  АЧХ-измерения, EQ-пресеты (PEQ/GEQ), тиры;
- `faq.json`, `methodology.json`, `articles.json` — текстовые разделы.

После правки JSON просто обновите страницу — сервер отдаёт их без кэша.

## Что изменилось относительно старого Terviona

- **Удалены целиком**: магнитные клавиатуры, механические клавиатуры,
  магнитные свитчи — данные, страницы, маршруты, фильтры, i18n-строки,
  иконки, изображения. Остались только **Мыши** и **Аудио**.
- **Новый дизайн** в духе Nothing: чистый чёрно-белый монохром без единого
  цветового акцента, dot-matrix фирменный знак и текстуры, плоская навигация,
  строгие хайрлайны, моноширинные технические подписи.
- **Бренд**: тир-рампа от белого (SS) к тёмно-серому (F), новый dot-matrix
  логотип, подпись основателя в футере.
