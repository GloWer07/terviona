# Terviona — заметки для агента

Статический сайт без сборки: HTML + CSS + JS, контент в JSON. Корень сайта — `site/`.

## Как проверить изменение

```sh
python3 local_server.py --port 8765
```

Затем открыть `http://127.0.0.1:8765/`. Маршруты повторяют продакшен: `/`, `/mice`, `/mice/<device>`, `/audio`, `/articles`, `/methodology`, `/faq`, `/contact`, `/user/…`. Сервер отдаёт файлы без кэша.

## Где что лежит

- `site/data/` — весь контент: `mice.json` (152 записи), `audio.json` (105), `faq.json`, `articles.json`, `methodology.json`, `pricing.json`, `meta.json`. Правка JSON видна сразу после обновления страницы.
- `site/css/style.css` — дизайн-система v4 «DOT MATRIX» в духе Nothing: чёрно-белый монохром, хайрлайны, моноширинные подписи, без цветовых акцентов.
- `site/js/app.js` — ядро; рядом `category.js`, `i18n.js`, `auth.js`, `reviews.js`, `profile.js`, `article.js`.
- `tools/trace_shapes.py` — вспомогательный скрипт для форм корпусов.

## Правила проекта

- Никаких сборщиков и зависимостей: файлы отдаются как есть.
- Строки интерфейса — через `site/js/i18n.js` (ru/en), без хардкода в разметке.
- `site/js/supabase-config.js` — заглушка локальной сборки; авторизация и отзывы выключены, менять её без запроса не нужно.
- Не добавляй цветовые акценты в CSS: бренд строится на монохроме.
